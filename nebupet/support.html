NebuPet 使用支持

联系支持前，请勿发送 API Key、完整聊天记录或其他敏感信息。

模型连接失败

检查 Base URL 是否包含服务需要的 API 前缀、Model Name 是否完全一致，以及 API Key 是否仍有效。 公网地址必须使用 HTTPS。

局域网模型无法访问

确认 iPhone 与模型服务位于同一网络，并在系统设置中允许 NebuPet 使用本地网络。 Ollama 等服务还需要监听可被手机访问的地址。

回复中断或超时

NebuPet 会显示明确错误，失败请求不会产生虚假的宠物回复或成长。 确认模型服务恢复可用后重新发送即可。

导出或删除数据

在“数据管理”中可以导出 JSON 备份。删除功能会同时移除本地数据库内容和 Keychain 中的 API Key， 且无法恢复。

联系支持

请发送问题描述、NebuPet 版本和 iOS 版本至 610186215@qq.com。 不要发送 API Key 或私密对话内容。
