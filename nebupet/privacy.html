NebuPet 隐私政策

生效日期：2026 年 7 月 30 日 · 开发者：Chen Zhifeng

1. 本地数据

NebuPet 将宠物资料、聊天记录、长期记忆、成长数据和模型配置保存在用户设备上的本地数据库中。 开发者没有用于接收或保存这些数据的服务器。

2. 模型请求

为了生成回复，NebuPet 会把当前消息、必要的近期对话、所选长期记忆和宠物状态发送到用户自行配置的模型服务。 模型服务如何处理这些数据，由用户与该服务提供方之间的条款和隐私政策决定。

3. API Key

API Key 保存在 Apple Keychain 中，不写入聊天数据库，不包含在数据导出文件中，也不会发送给 NebuPet 开发者。

4. 数据导出和删除

用户可以在 App 内导出本地 JSON 数据，也可以删除宠物、聊天、记忆、模型配置和 Keychain 中的 API Key。 删除操作无法撤销。

5. 跟踪、广告和账号

NebuPet 不包含广告、分析或跨 App 跟踪 SDK，也不要求用户创建 NebuPet 平台账号。

6. 第三方模型服务

用户自行决定连接哪个模型服务并负责阅读其条款。NebuPet 只把请求发送到用户配置的地址， 不通过开发者运营的 AI 中转服务器。

7. 联系方式

隐私问题请发送邮件至 610186215@qq.com。 请勿在邮件中发送 API Key、完整聊天记录或其他敏感数据。

English summary

NebuPet stores pet profiles, conversations, memories, growth data, and model settings locally on the user’s device. API keys are stored in Apple Keychain and excluded from exports. Necessary prompt context is sent only to the model endpoint configured by the user. The developer does not operate an AI backend and does not receive or retain that content. The app contains no advertising, analytics, or tracking SDKs.
