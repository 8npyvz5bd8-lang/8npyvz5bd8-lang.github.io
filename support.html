Support

Fix the file without exposing the business.

Most import problems can be resolved from a stable error code and the field specification. You should never need to send a source CSV.

Keep merchant data private.
Send the diagnostic summary, not the file.

Start with the code

Open Error help and search the exact code displayed by the app. The catalog explains the reason and correction from the same source used by ProfitSift.

Check compatibility

Confirm that the file is UTF-8 or UTF-8 with BOM, uses a comma or tab delimiter, and follows the CSV field specification. Sales files are limited to 50,000 data rows; Cost and Fee files to 10,000 each; every file to 25 MB.

What to send

Use Copy Diagnostic Summary in the app. It contains only the app version, macOS version, row counts, mapped ProfitSift field names, and error code.

Do not send sensitive source details.Do not send your CSV, file name, file path, amounts, customer details, source column names, or other business data.

Contact

Email 610186215@qq.com. An automated response may point to documentation; it does not mean the problem has been resolved.

Subscriptions and billing

Open Plans in ProfitSift to purchase or restore a subscription. Use Manage Subscription, or open App Store account settings, to change or cancel a plan. Apple handles billing and refund requests. A verified subscription changes only the sales-row limit; all audit features remain available on Free.
